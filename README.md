## 🚀 Cómo desplegarlo (gratis, con GitHub Pages)

1. Crea un repositorio público llamado `portafolio` en GitHub.
2. Sube `index.html`, `styles.css`, `script.js` y `avatar.jpeg` a la raíz del repo.
3. Ve a **Settings → Pages → Source: Deploy from a branch → main /(root)** → Save.
4. Espera 1-2 minutos: tu sitio estará en `https://tuusuario.github.io/portafolio/`.
